# Nexora — Premium Software Company Website

Static bilingual (Arabic/English) company website ready for GitHub Pages.

## Included
- Responsive premium landing page
- Arabic RTL + English LTR
- Language switcher with localStorage
- Home, Services, About, Work, Process, Contact sections
- Mobile navigation
- Scroll reveal animations
- Contact form front-end demo
- No framework or build step required
- Works directly on GitHub Pages

## Run locally
Open `index.html` in a browser.

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders while preserving the structure.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

## Customize
Replace:
- `Nexora` with your company name.
- `hello@nexora.dev` with your real email.
- Project names and descriptions.
- LinkedIn / Instagram / X links.
- Stats and company text.

The contact form is intentionally front-end only. To receive submissions, connect it later to Formspree, EmailJS, a serverless function, or your own API.
